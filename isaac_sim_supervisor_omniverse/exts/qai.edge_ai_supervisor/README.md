# Edge AI Warehouse Supervisor panel

This Isaac Sim extension displays the live, atomic status emitted by
`scripts/run_live_isaac_evk_supervisor.py`.

It shows the exact clean roof-camera frames sent to Cosmos Reason2, the exact
prompt and allow-listed outputs, live inference timing, raw model responses,
the accepted policy-gateway command, and the current simulator route state.

The panel opens automatically and is also available from
**Window → Edge AI Warehouse Supervisor**.
