# Qualcomm Dragonwing billboard source

The wall billboard uses `Dragonwing-Logo-Cropped.png` as its Unreal import
source. It is a pixel-exact crop of `resources/dragonwing-logo.png`: only the
excess white space above and below the official mark was removed, leaving a
24 px vertical safety margin. Unreal composites it over a separately shaded
white sign face.

The previous Qualcomm-only vector and raster files remain as source history
but are no longer applied to the wall sign.

Source page:
https://commons.wikimedia.org/wiki/File:Qualcomm-Logo.svg

Original vector URL:
https://upload.wikimedia.org/wikipedia/commons/f/fc/Qualcomm-Logo.svg

The source page identifies Qualcomm as the original author and traces the mark
to Qualcomm presentation material. Qualcomm and its wordmark remain trademarks
of their respective owner. These files are included only for this private demo
and must not be treated as a grant of trademark rights.
